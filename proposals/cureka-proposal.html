06 / Platform Capabilities

Platform Capabilities

Out of the Box Controls

Every AI Voice Agent built on the Highvance platform includes the following controls out of the box:

◈

Call Scheduling & Routing

Working Days & Hours
Set the exact days and hours (IST) outbound calls are allowed to fire; leave unselected to run 24/7. Test calls always work regardless of the schedule
Call Timing Controls
Configurable max call duration, ring timeout, and a no-response cut-off that auto-hangs up on prolonged caller silence
Multi-Provider Telephony
Mix telephony providers (e.g. Plivo, Twilio) on a single agent, with round-robin rotation across multiple calling numbers and a max-calls-per-number cap
◈

Retry & Follow-Up Logic

Automatic Retries
Re-attempts calls that hit a busy signal, go unanswered, or land on voicemail/answering machine
Custom Retry Situations
Additional outcomes flagged by post-call analysis (e.g. call dropped, asked to call later) can also trigger a retry
Configurable Retry Rules
Set the maximum retry attempts and the interval between attempts
Auto Call-Back
If a caller asks to be called back at a specific time, the agent confirms it and the system schedules the call automatically
